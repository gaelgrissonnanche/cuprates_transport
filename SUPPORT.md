# Support

## Questions and usage help

Open a GitHub issue at
<https://github.com/gaelgrissonnanche/cuprates_transport/issues>. Include a
minimal script, the complete traceback, your operating system, Python version,
package version or Git commit, and installation method.

For numerical questions, also include the band parameters, resolution,
magnetic field, temperature, scattering model, time-integration settings, and
the convergence checks already performed.

## Bug reports

A useful bug report contains:

- the smallest input that reproduces the problem;
- observed and expected behavior;
- whether the issue occurs at zero field, zero temperature, or in an analytic
  limit;
- any warnings or non-finite values;
- enough metadata to reproduce the environment.

## Scope

Best-effort community support is provided through the public issue tracker.
The software is research code and comes without warranty. Users remain
responsible for checking numerical convergence and physical applicability to
their system.
